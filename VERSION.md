# Version History

| Version | Changes |
| :--- | :--- |
| **Version 1.2.0** | **NEW FEATURES**<br>- **Record Changes When No GM Is Online:** Changes players make while no GM is logged in are now recorded. The player's own client saves each change on the character, and the changes are added to the log the next time a GM logs in. Entries recorded this way are marked `No GM` in the log window and in exports. This can be turned off with the new `Record Changes When No GM Is Online` setting.<br><br>**IMPROVEMENTS**<br>- Logged changes now show the previous value as well as the new one (for example, `Strength: 50 ➔ 55`).<br><br>**BUG FIXES**<br>- In the categorical view, a single change to several stats now appears under every stat it changed, not just the first.<br>- The Export and Clear buttons on each player row now show their tooltips in the same style as the other buttons in the window.<br>- Made the dashed line beside each entity in the categorical view thicker so it is easier to see.<br><br>**UNDER THE HOOD**<br>- Changes queued while no GM is online are stored in a `pendingLogs` flag on the actor, one key per entry, so players who share a character cannot overwrite each other's entries. The GM client merges them in time order, skips any it has already merged, and drops any entry that names a user who does not own that actor. |
| **Version 1.1.0** | **NEW FEATURES**<br>- **Categorical View:** Added a view toggle to switch between a chronological timeline and a categorical view (grouping changes by entity to easily review the history of a specific stat, item, or effect).<br><br>**IMPROVEMENTS**<br>- Added tracking of modifications made to embedded items (`system`) and active effects (`changes`).<br>- Added a confirmation dialogue to the `Clear All` button to prevent accidental deletions.<br>- Added a timestamp to the export filename. |
| **Version 1.0.0** | **Initial Release** |
