# Version History

| Version | Changes |
| :--- | :--- |
| **Version 1.2.0** | **NEW FEATURES**<br>- **A new look for the log window:** One player's log is shown at a time: pick a player from the list on the left, and their characters appear as cards beside it, with the time of each change in its own column. A bar above the log holds the player's stats, the `Timeline` and `By category` switch, `Expand reverted changes`, and the refresh, export and clear buttons. The window now has gold and blue accent colours to choose from (the palette button beside `Players`), and follows Foundry's light or dark interface theme.<br>- **Record Changes When No GM Is Online:** Changes players make while no GM is logged in are now recorded. The player's own client saves each change on the character, and the changes are added to the log the next time a GM logs in. Entries recorded this way are marked `No GM` in the log window and in exports. This can be turned off with the new `Record Changes When No GM Is Online` setting.<br><br>**IMPROVEMENTS**<br>- Logged changes now show the previous value as well as the new one (for example, `Strength: 50 ➔ 55`).<br>- Changes a player makes and then undoes themselves (such as adding an effect and later removing it, or changing a stat and changing it back) are folded into a single dashed line in the log window. Use the new `Expand reverted changes` button to see every original entry. Nothing is removed from the log or from exports.<br>- Clearing one player's log now asks you to confirm first, as clearing all logs already did. Both confirmations name exactly what will be deleted, and Cancel is the default, so pressing Enter alone never deletes anything.<br>- In the categorical view, a stat, item or effect with a single change shows that change directly, with no extra click.<br>- Characters you open or close stay that way when you refresh the window or switch views.<br><br>**BUG FIXES**<br>- Changes to an active effect are now logged in full: turning it on or off, its modifiers, its duration and its status conditions. Previously most of these changes were missed.<br>- In the categorical view, a single change to several stats now appears under every stat it changed, not just the first.<br><br>**UNDER THE HOOD**<br>- Changes queued while no GM is online are stored in a `pendingLogs` flag on the actor, one key per entry, so players who share a character cannot overwrite each other's entries. The GM client merges them in time order, skips any it has already merged, and drops any entry that names a user who does not own that actor.<br>- The window's styles are rebuilt on a new set of design tokens (`styles/character-tracker-theme.css`) scoped to the module's own elements, replacing the shared `filroden-theme.css` variables on `:root`. Three typefaces (Atkinson Hyperlegible, Sora and Barlow Semi Condensed, all SIL Open Font License) are now included, with their licences in `fonts/`.<br>- Action names are now localised for display. They are still stored and exported in English. |
| **Version 1.1.0** | **NEW FEATURES**<br>- **Categorical View:** Added a view toggle to switch between a chronological timeline and a categorical view (grouping changes by entity to easily review the history of a specific stat, item, or effect).<br><br>**IMPROVEMENTS**<br>- Added tracking of modifications made to embedded items (`system`) and active effects (`changes`).<br>- Added a confirmation dialogue to the `Clear All` button to prevent accidental deletions.<br>- Added a timestamp to the export filename. |
| **Version 1.0.0** | **Initial Release** |
